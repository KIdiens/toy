# ADR-012: 设计令牌契约——颜色只经语义变量，图标只用 Lucide

## Status
Accepted (2026-09-21)

## Background
团队级 P0 规则：**禁止紫色→粉色渐变**；**禁止硬编码颜色值**（唯一例外 `#fff`/`#000`）；**禁止 emoji 充当功能图标**。若无统一契约，生成式产出极易在样式层散落字面色值与第二套图标，破坏一致性且无法门禁。

## Decision
`host/web/design/design-tokens.css`（设计师产出，`design-tokens.json` 为机器可读镜像）是**唯一允许出现字面色值**的文件（SVG 内的 `#fff`/`#000` 例外）。所有界面颜色必须经语义化 CSS 变量引用：

架构只锁**规则**，不替设计师点名令牌；令牌名与取值以 `design-tokens.css` 为唯一真源。规则：

1. 所有颜色/间距必须经 CSS 变量引用，禁止字面色值（例外仅 `#fff`/`#000`）。
2. 唯一落点 `host/web/design/design-tokens.css`；新增语义色先在该文件加令牌。
3. 禁止紫色→粉色渐变。
4. 图标统一 Lucide（ADR-009），颜色用 `currentColor`，尺寸遵循设计规范图标阶梯。
5. 门禁：静态资源 `grep -E '#[0-9a-fA-F]{3,8}|rgb\(|hsl\('` 命中即不合格（`design-tokens.css` 与 `#fff`/`#000` 除外）。

「语义角色 → 实际令牌」导航映射（以文件为准，仅便于实现者按语义定位）：

| 语义角色 | 令牌（以 `design-tokens.css` 为准） |
|----------|-------------------------------------|
| 页面背景 / 卡片表面 / 三级表面 | `--bg` / `--surface` / `--surface-warm` |
| 主/次/副文本 / 元数据 | `--fg` / `--fg-2` / `--muted` / `--meta` |
| 边框 / 内部分隔 | `--border` / `--border-soft` |
| 主操作强调 | `--accent`（+ `--accent-hover/active/soft/on`） |
| 状态：成功·到位 / 警告·未装公仔 / 故障·急停 / 信息 | `--success` / `--warn` / `--danger` / `--info` |
| 领域：限位 / 连接 / 四轴轨道 / 播放指针 | `--limit-*` / `--conn-*` / `--track-1..4` / `--playhead` |
| 间距 / 圆角 / 字号 / 字重 / 行高 / 字距 | `--space-*` / `--radius-*` / `--text-*` / `--fw-*` / `--leading-*` / `--tracking-*` |

> 已知缺口（非阻断）：图标尺寸未令牌化（设计规范为固定阶梯 16/20/24px）；如需门禁化，请设计师增 `--icon-*` 令牌，在补齐前以 `DESIGN.md` 图标阶梯为准。

## Consequences
- 正面：颜色与图标单点可控，可被脚本门禁；换肤/对比度调整只改一处；杜绝紫粉渐变与 emoji。
- 负面：新增颜色需先加令牌，略增流程。
- 协同：设计师负责令牌取值与视觉规范，架构负责「必须用令牌」的约束与门禁。
