# ADR-013：补齐直接代办完成句式的输出审核

## Status
Accepted（2026-10-22）。关闭登记问题 OD-8；C12、C13 继续待验证。

## Background
原后置规则要求出现“把/将”，使“我替你转账了”等直接代办完成句式被放行，并可能原样进入 TTS。该问题已登记为 OD-8。讲故事、询问是否完成、设置付款提醒等正常内容需要保留。

## Decision
- 保留原前置规则与把/将后置规则，新增直接代办分支：句段开头的第一人称、帮/替、受益对象、既有现实动作词及完成体。支持常见时间修饰、嵌套“给妈妈”等对象及有界宾语。
- 新分支不跨越否定、疑问和引用边界。“故事里/在这个故事中”等明确引导只作用于当前句，不因为整段出现“故事”就免审。
- 匹配继续复用 NFKC 与格式字符归一化；通过审核的朗读文本保持原有保守处理。
- 不实完成声称在 TTS 合成前替换为既有 `CANNOT_FABRICATE_TEMPLATE`，不增加新的现实事务工具。

## Verification
`tests/unit/test_benefactive_claim_safety.py` 包含 20 条声称、24 条正常内容对照，以及合成前替换和正常内容原样合成的检查，共 69 项。对照为软件测试人工构造，不是真实儿童内容安全评测。

全量回归 1704 passed / 3 skipped；删除新分支、绕过合成前审核、把故事当成整段放行条件、删除局部故事边界，四种进程内变异均被相应断言检出。证据位于 `data/od8-safety-20261022/`。

## Consequences
登记样例及本分支覆盖的直接代办句式不再漏放，OD-8 按原关闭条件结案。规则仍受有限词表、句段长度和语义歧义约束；本轮没有穷尽所有汉语表达，也没有解决旧前置规则中已登记的 C13 误拦。真实模型、复杂转述和未覆盖表达继续按 C12/C13 验收，不能据此宣称整体内容安全已通过。
