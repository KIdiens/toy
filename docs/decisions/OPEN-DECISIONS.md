## 明细

### OD-1 固件协议增补（版本号 / CRC / 每帧 ACK / 故障码）
- **现状**：`motion_controller.ino` 协议为纯行文本（`STATE`/`ARM`/`FRAME`/`STOP`/`SETTLED`/`FAULT`/`ERR`），无协议版本号、无 CRC 校验、无逐帧 ACK、故障码是**字符串枚举**（`INTERLOCK_OR_TIMEOUT`/`PWM_INIT`）而非数字码。
- **为何本阶段不做**：这四类增补**全部要动固件**，而本阶段无 ESP32/真板；改了也**无法验证**，属开发书 §20 明确要求"实物证据"的范畴（以模拟/格式检查替代实物证据是违规的）。
- **触发条件**：拿到真板 → 完成开发书 §9.2 所述"起步测试" → 再评估是否增补。
- **临时约定**：主机侧解析以 Spec §7.2 协议表为唯一真源；`sim/` 逐字复刻现有字符串协议，**不提前引入**这些增补。

### OD-2 帧序号回绕规则
- **现状**：固件帧序号为 32 位 `unsigned long`，开发书 §9.2 要求"序号回绕规则"但**未定义**；主机侧 Python 整数无界，无此限制。
- **测算**：按 20ms/帧 → `2³² × 20ms ≈ 2.7 年`才回绕。
- **处置**：登记，**不给优先级**（Lead 裁定）。回绕前会被 300ms 看门狗/停机/重 ARM（`haveSeq=false` 复位）覆盖绝大多数场景。
- **触发条件**：长时压测（≥ 数天连续运动）或量产前评审。

### OD-3 限位真源与固件的长期收敛
- **已定死（T1，不可协商）**：**主机侧限位真源 = 角色配置 `min_us` / `max_us`**（开发书 §9.3）；固件 `1400–1600μs` 仅作**台架保守值保留不改**；主机侧动作校验/下发**不依赖**固件放宽限位。两边各自成立。
- **未定**：开发书 §6.4"先 1500±50 再逐步扩大"的**更大行程**方案——固件上限写死 1600，如何"逐步扩大"未定义。
- **触发条件**：需要更大行程 + 真板实测后，再将正式方案转为 ADR。
- **另注**：固件侧与主机侧的限位一致性由 `tests/contract/test_protocol_parity.py` 持续守护。

### OD-4 `previousSeq` 重放防护的规格化
- **现状**：固件 `stopMotion()` **不重置** `previousSeq`；主机每轮从 0 重发，若**不重新 ARM** 就会触发 `ERR FRAME`；重 ARM 后因 `haveSeq=false` 可复位。
- **裁定（Lead）**：这是**有意的重放防护，非缺陷**。模拟器逐字复刻（`sim/controller.py`），`20-mcu-simulator.md` §3 已列为保真要点（架构 §10.2 D3）。
- **未定**：是否把该行为写入对外规格、或加显式"重置序号"接口以便特定场景。
- **触发条件**：真板验证重放防护边界后。

### OD-5 图标尺寸令牌化（`--icon-*`）
- **现状**：`design-tokens.css` 已覆盖颜色/间距/圆角/字号等，但**图标尺寸未令牌化**；设计规范给固定阶梯 16/20/24px（16px 描边 1.75）。
- **处置**：在补齐前，图标尺寸以 `host/web/design/DESIGN.md` 图标阶梯为准；架构侧门禁暂只覆盖**颜色**（无字面色值）。
- **触发条件**：需要把图标尺寸纳入自动化门禁时，设计师在 `design-tokens.css` 增 `--icon-*`。

### OD-6 前端 TS 类型声明 / MSW Mock 生成
- **裁定（Lead 答复2）**：**不做**。与 ADR-007「前端无构建链」冲突。
- **契约运行时落点**：后端 `host/web/schemas.py`（Pydantic，OpenAPI 自动产出）+ 前端 `host/web/static/api.js` 运行时校验。`../api/openapi.yaml` 仍为前后端**唯一契约**，只是**不生成**需要 Node 工具链的 `.d.ts`/MSW Mock。
- **触发条件**：若未来引入 Node 工具链（如 React + Vite 迁移），再评估。

### OD-7 真实云 AI 接入
- **现状**：本阶段不接阿里云百炼；`host/ai/stub_provider.py` 与 `qwen_provider.py` **形状完全一致**，`AI_PROVIDER` 一处切换。
- **未定**：真实准确率/延迟/音色/费用/限流阈值（Spec §10.1 C9）。
- **触发条件**：拿到 `DASHSCOPE_API_KEY` 后跑同一份契约测试（`tests/contract/test_provider_contract.py`）。
