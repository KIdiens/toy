连接指引 · 前置条件

  • 公仔插到位（Dock 到位信号有效）。
  • 急停处于健康状态（常闭触点闭合）。
  • 公仔电阻编号与角色配置文件一致，且编号稳定 ≥200ms。
  • 主机已启动本机服务：python -m host.main --simulate，页面与接口同源。

任一条件不满足，动作都不会下发到设备；这不是错误，而是安全联锁的正常表现。
